# Rock Paper Scissors

A Rock Paper Scissors game built as part of [The Odin Project Rock Paper Scissors Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) curriculum to practice JavaScript fundamentals, event handling, and building simple interactive applications.

---

## Features

* Play against the computer
* Random computer choices
* Score tracking system
* First to reach winning score wins
* Reset game functionality
* Interactive button-based UI
* Real-time result display

---

## Tech Stack

* JavaScript
* HTML
* CSS

---

## What I Learned

* JavaScript fundamentals (functions, conditionals)
* DOM manipulation
* Event listeners
* Random number generation
* Game state management
* Basic UI updates based on logic

---

## Challenges

* Writing clean game logic without repetition
* Handling win/lose/draw conditions properly
* Keeping score state consistent
* Updating UI without bugs during gameplay
